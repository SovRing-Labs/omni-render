# uax14 — Unicode Line Breaking Algorithm

- **Spec:** UAX #14 (Unicode 18.0.0), https://www.unicode.org/reports/tr14/ — §5.1 classes (Table 1), §6.1 rules LB1–LB31 (default tailoring §6.2), LB1 resolution table.
- **Data:** `tests/data/LineBreak.txt`, `EastAsianWidth.txt`, `UnicodeData.txt`, `emoji-data.txt` (UCD 18.0.0). Generated by `tools/gen_uax14.py` → `src/uax14_tables.rs` (4,237 runs).
- **Code:** `src/uax14.rs` (engine), `src/uax14_tables.rs` (generated), `tests/uax14.rs` (conformance).
- **Conformance:** `tests/data/LineBreakTest.txt` (UCD auxiliary, 18.0.0): **19,346 / 19,346 pass** (`cargo test --test uax14 -- --nocapture`).
- **Known gaps:** none against LineBreakTest. Not covered: LB28a/LB26–27 Korean and Brahmic cases only through the test file; no tailoring hooks (CJ/AI/SA tailoring of §8 is not offered); the `$EastAsian` set is F/W/H only, per spec.

## API
- `uax14::props(char) -> Props` — class, EAW{F,W,H}, Extended_Pictographic, general category (pre-LB1).
- `uax14::breaks_chars(&[char]) -> Vec<Break>` — break gaps as character indices.
- `uax14::break_opportunities(&str) -> Vec<Break>` — same, as byte offsets.
- `Break { index, mandatory }` — `mandatory` = LB3/LB4/LB5 breaks (BK, CR, LF, NL, end of text). LB2: never a break at index 0.

## Rules
Evaluated in order; first decision wins (see `decide` in `src/uax14.rs`, one comment per rule id). LB9 folds CM/ZWJ into their base via `units()`; LB10 turns leftover CM/ZWJ into AL.
